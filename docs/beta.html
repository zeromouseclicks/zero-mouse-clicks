Ask your AI chat.
Get the plan set.

Zero Mouse Clicks is AI-native. From ChatGPT, Claude, Gemini or any AI assistant, ask for the plans of an apartment: the assistant searches for the project and its floor plan, and Zero Mouse Clicks draws the six A3 sheets in your browser. Free, and still zero tokens on our side.

Beta · it changes often, always to get better

1. Any AI chat, nothing to install

Copy this into your chat and fill in the brackets:

Find the floor plan image of [apartment type] in [project name, city]
on the developer's or the listing's website. Then give me this link
with the image address and the area filled in:
https://zeromouseclicks.com/?plan=IMAGE_URL&area=AREA&unit=m2

Open the link the chat gives you. The floor plan loads by itself and the plan set starts: zero clicks. The drawing happens in your browser and nothing is uploaded.

Link partWhat it does
planDirect address of the floor plan image (JPG, PNG or WEBP). Required.
areaApartment area, a number. Optional: without it, the area is read from the plan.
unitm2 (private area) or sqft (gross area). Default m2.
go=0Loads the plan without starting, so you can check it first.

2. Add the Zero Mouse Clicks connector

With the connector, the chat opens the project page, picks the floor plan image and reads the area on its own. Add it as a custom connector (a remote MCP server) with this address and no authentication:

https://ebqxcaelgmxofwtofrdc.supabase.co/functions/v1/zmc-ai/mcp
  • Claude (web or desktop): Customize › Connectors, or Plugins › Add in newer versions, then Add custom connector; enter a name and the address. Free plans can add one custom connector.
  • ChatGPT: turn on Developer mode in the settings (paid plans), then create an app with the address and no authentication.
  • Gemini: in Connected Apps, add a custom app with the address, where your plan and country allow it.

It brings two tools: find_floor_plans opens one project page and returns the images that look like floor plans and the areas printed on it; plan_set_link returns the link that draws the plan set.

What a conversation looks like

  1. You“Make me the plans of the two-bedroom unit in [project], Bogotá.”
  2. ChatSearches the web and finds the project page.
  3. ConnectorFinds the floor plan and the area on that page.
  4. YouOpen the link: six A3 sheets in one PDF.

Good to know

  • This is a beta: it changes often, always to get better. Tell us what works and what does not through the contact form.
  • The connector opens only the page that you or the chat point to, one at a time, respects robots.txt and keeps no images. Some portals do not allow automated reading; for those, save the floor plan image and drop it on the site.
  • Pages built with JavaScript can hide their images from the connector. The chat can still find the image address, or you can save the image yourself.
