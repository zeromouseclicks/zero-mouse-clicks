Good to know

  • It is a beta: tell us what works and what does not through the contact form.
  • The connector opens only the page you or the chat point to, respects robots.txt and keeps no images. If a portal does not allow it, save the floor plan image and drop it on the site.
For developers: the link and the tools
Link partWhat it does
planDirect address of the floor plan image (JPG, PNG or WEBP). Required.
areaApartment area, a number. Optional: without it, the area is read from the plan.
unitm2 (private area) or sqft (gross area). Default m2.
go=0Loads the plan without starting, so you can check it first.

The connector brings two tools: find_floor_plans opens one project page and returns the images that look like floor plans and the areas printed on it; plan_set_link returns the link that draws the plan set.
