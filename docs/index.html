How it works

Send the picture.

No CAD file, no survey, no software to learn. The image you already have is the starting point.

  1. Email the floor planA JPG, PNG or the brochure PDF.
  2. Tell us the areaThe private area printed on the brochure, in m² or sq ft.
  3. Get the PDF backSix A3 sheets, ready to print, quote or file.

Under the hood

Small models.
Plain rules.

No cloud AI

Three models of about one megabyte each read the image. They run on an ordinary computer, so your plan is not sent to a chatbot.

Trained on synthetic plans

The models learned from apartments generated by code, not from anyone's copyrighted drawings.

Open source

The engine and the models are on GitHub under Apache 2.0. Read it, run it, improve it.

Honest by default

A first draft, not a survey.

Marketing plans are not drawn to scale, and this is an early prototype: it reads some plans well and gets others wrong. Heights and electrical points are standard assumptions. Every sheet carries the same note.
