Demandez à ChatGPT, à Claude ou à n'importe quel assistant IA les plans d'un appartement. Il trouve le plan; Zero Mouse Clicks dessine les six feuilles A3 dans votre navigateur. Gratuit.

Essayez maintenant · tout assistant IA, rien à installer

Inscrivez le projet, copiez le texte ou ouvrez-le directement dans votre assistant.

Encore mieux : ajoutez le connecteur une fois

Une minute, depuis un ordinateur. Ensuite, l'assistant trouve seul le plan et la superficie.

L'adresse à coller, sans authentification :

https://ebqxcaelgmxofwtofrdc.supabase.co/functions/v1/zmc-ai/mcp

Claude : les forfaits gratuits peuvent ajouter un connecteur personnalisé. ChatGPT : mode développeur, forfaits payants, sur le Web. Gemini : Applications connectées › ajouter une application personnalisée, si votre forfait et votre pays le permettent.

Bon à savoir

  • C'est une bêta : dites-nous ce qui marche et ce qui ne marche pas avec le formulaire de contact.
  • Le connecteur n'ouvre que la page indiquée par vous ou par l'assistant, respecte robots.txt et ne garde aucune image. Si un portail ne le permet pas, enregistrez l'image du plan et déposez-la sur le site.
Pour les développeurs : le lien et les outils
Partie du lienCe qu'elle fait
planAdresse directe de l'image du plan (JPG, PNG ou WEBP). Obligatoire.
areaSuperficie de l'appartement, un nombre. Facultatif : sinon, elle est lue sur le plan.
unitm2 (superficie privative) ou sqft (superficie brute). Par défaut m2.
go=0Charge le plan sans démarrer, pour le vérifier d'abord.

Le connecteur apporte deux outils : find_floor_plans ouvre une page de projet et renvoie les images qui ressemblent à des plans et les superficies affichées; plan_set_link renvoie le lien qui dessine le jeu de plans.
